PHOTO CHECKLIST FOR WHOLESALE CONNECT
========================================

How it works: every photo spot on the site already has a name. Until you add a real photo,
the site shows a placeholder drawing. When you add a photo with the exact file name below,
the site shows your photo instead, with the charcoal/amber tint applied automatically.

Photo rules:
  - File type: .jpg   (not .png or .jpeg; rename or ask Claude to convert)
  - Shape: landscape, roughly 4:3 (for example 1200 x 900 pixels)
  - Keep each file under about 400 KB so the site loads fast
  - Put every photo in the 'images' folder in the GitHub repo
  - No visible people or faces; avoid photos of other companies' logos
